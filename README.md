# corbett-water-reports

Corbett Management Reports — interactive irrigation reporting websites.

This repository hosts public Corbett Smart Water Management account reporting pages through GitHub Pages.

## Architecture

Shared website styling and behavior:

- `assets/css/`
- `assets/js/`

Account-specific reporting pages:

- `accounts/cma-###/`

Approved reporting data is generated outside this repository and then converted into account-specific web data for publication.
